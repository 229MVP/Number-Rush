# CodeCanyon Listing — Number Rush

**Item name:** Number Rush — Neon Number Puzzle Game React Native Expo Template

**Category:** Mobile → Games → App Templates → Puzzle

## Item description

Number Rush is a neon arcade number-puzzle game template for React Native
and Expo. Players place number tiles into four lanes, aiming to land exactly
on 21 for a Perfect clear while avoiding a Bust past 21. Three strikes end
the run. A combo multiplier rewards consecutive Perfect clears, and two
power-ups (Multiplier, Swap) add light strategic choice without a shop or
in-app economy.

This CodeCanyon listing covers the **Classic-only sellable template**:
complete gameplay, tutorial, local persistence, and documentation — no
backend, accounts, or monetization is included or required to run it.

### Live preview

Provide a hosted Expo Web export (`npx expo export --platform web`, then
deploy `dist/`) as the CodeCanyon live preview link. See
`docs/DEMO_VIDEO_SCRIPT.md` for a suggested walkthrough video script.

### Features

- Fully playable Classic Rush 21 mode with exact scoring/combo rules
- Responsive across common phone breakpoints and Expo Web
- First-time tutorial using measured element positions (not hardcoded %)
- Local best-score + stats persistence via AsyncStorage
- Settings: audio, haptics, reduced motion, high contrast, resets
- Clean, documented, typed TypeScript source
- Automated unit tests for the core gameplay rules
