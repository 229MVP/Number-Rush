This document lists every included asset category, its source, and its
license status. **Do not** redistribute this template with any asset marked
"buyer must replace" left in place for a commercial release beyond this
template's own license terms.

Godot port of this game and are **not used by the React Native app** — they
are excluded from the sellable release folder (see `release/FILE_MANIFEST.md`).

## Summary

- **No third-party stock art, stock photos, or purchased icon packs are bundled.**
- All visual chrome (grids, glow, particles) is code-generated, not image assets.
- All audio is original and programmatically generated — safe to keep or replace.
- Font and icon-library dependencies are open-source, commercially redistributable, and loaded via npm packages (Google Fonts, Lucide) rather than bundled binary files.
- Leftover Godot-port asset files (`assets/fonts/*.ttf`, `assets/icons/*.png|svg`, and their `.import` metadata) are unused by this template and excluded from the sellable release folder.
