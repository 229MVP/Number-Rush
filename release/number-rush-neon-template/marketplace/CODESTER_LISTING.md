A polished neon arcade number-puzzle game template built with Expo, React

## Description

Number Rush is a fast, satisfying number-puzzle loop: place tiles into one of
four lanes, land exactly on 21 for a Perfect clear, chain your combo, and
survive three strikes. This template ships the complete, tested Classic game
loop plus a first-time tutorial, two stable power-ups (Multiplier, Swap),
local best-score tracking, and a lightweight Stats screen — all wrapped in a
production-quality neon visual style.

Built as a clean, well-typed React Native/Expo codebase, this is a strong
starting point for your own puzzle game, a portfolio piece, or a paid reskin
project for a client.

### Included

- Complete, stable Classic Rush 21 gameplay loop
- First-time tutorial with responsive spotlight positioning
- Multiplier and Swap power-ups
- Local best-score tracking and a Stats screen (AsyncStorage — no backend)
- Settings (audio, haptics, reduced motion, high contrast, resets)
- Responsive layout for common phone sizes + Expo Web support
- Full TypeScript source, reusable game-engine module
- Documentation: setup, customization, game rules, asset licenses

### Not included

- Backend / server
- Online accounts or cloud save
- Live/online leaderboard
- Ads or in-app purchases
- App Store / Google Play submission or publishing services
